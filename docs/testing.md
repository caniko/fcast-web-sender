# Testing

Fast deterministic checks:

```sh
just schema-check
just rust-fmt
just rust-test
just rust-clippy
just rust-doc
just ts-check
```

Rust unit tests cover frame limits, typed controls, trust-file permissions and
failure atomicity, credential-lease scope, mDNS query parsing, manifest
transforms, SSRF policy, and the local resource server. `tests/fixtures/`
contains HLS, DASH, mDNS, and bridge inputs for future integration coverage;
current unit tests do not all consume those files. No test requires a cloud
service or a real receiver.

Dependency-policy checks are separate because the advisory database requires
network freshness:

```sh
just security-check
```

The CI workflow generated by Simit runs the Rust gates in the rs-harbor Nix
shell. The project-owned frontend workflow runs the pinned pnpm workspace and
packages both browser manifests without publishing. It supplies esbuild from
Nix rather than executing an npm-installed native binary.

The tag workflow is the CD path: it runs `nix run .#local-check-release`,
builds `fcast-companion` through the rs-harbor derivation, packages the
extensions, and publishes checksummed GitHub release artifacts. The flake
cross builds for ARM64 Linux and Windows are independently buildable; Windows
skips only execution of its foreign-binary test phase.
